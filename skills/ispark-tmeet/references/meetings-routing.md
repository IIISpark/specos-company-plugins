# 会议管理

完成本节路由与风险判断后，再读 `tmeet-meeting.md` 获取所需子命令参数。

所有命令先确认登录态，并用 `tmeet meeting --help` 获取当前参数。时间必须使用带时区的 ISO 8601；
结束时间早于或等于开始时间时先澄清，不能猜测跨天意图。

查询路由：仅有时间范围用 `meeting list` 或 `list-ended`；已有会议号用 `meeting get`；含主题、
创建人或备注关键词用 `meeting search`，不要把关键词硬塞到 list。首次查询只取一页，后续分页游标
必须原样使用上一响应的 `next_page_token`；用户未要求全部时先询问是否继续。

创建会议需要主题、开始时间和结束时间等必填值。更新、取消和受邀人增删/替换会影响他人，必须先
展示会议号、目标、变更字段和影响，等待用户下一条明确确认后再执行。多个候选会议或成员不得自行选择。

向用户回显时只使用会议主题、时间、会议号、入会链接和必要的受邀成员信息；隐藏内部会议 ID、令牌
和未请求的敏感字段。输出较大的列表优先使用 `--compact`（若客户端支持）。
