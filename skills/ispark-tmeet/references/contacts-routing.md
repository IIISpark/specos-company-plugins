# 通讯录的受限使用

确认本节门禁通过后，再读 `tmeet-contact.md` 获取所需子命令参数。

`tmeet contact` 不是通用人员检索接口。只能在本轮已经明确存在以下后续动作时使用：

- 将该成员加入会议；
- 在正在进行的会议中呼叫该成员入会。

先确认下游会议动作、目标会议和用户给出的姓名/手机号/邮箱。若用户只想知道某人的部门、职位、
联系方式、是否存在或其他人员信息，拒绝查询并说明此能力仅服务于会议邀请或呼叫。

读取 `tmeet contact --help` 和所选子命令 help 后再执行。优先使用紧凑输出，仅将解析得到的内部
成员标识传给紧随其后的邀请/呼叫命令，不在面向用户的回复中回显手机号、邮箱、工号或原始标识。

多条匹配必须让用户选择。唯一匹配也不能用于踢出、等候室移动或其他会中管理；这些操作的目标
只能来自当前会议的参会人或等候室报告。
