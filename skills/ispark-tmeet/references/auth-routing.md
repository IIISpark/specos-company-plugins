# 认证与前置条件

读取命令语法、参数和当前错误提示前，再读 `tmeet-auth.md`。

先检查 `tmeet` 是否存在，再运行 `tmeet auth status`。状态输出可能包含身份和凭证有效期；
只向用户说明“已登录/未登录/需要重新登录”，不得回显原始身份标识、AccessToken 或 RefreshToken。

未登录时，说明需要 OAuth 授权。`tmeet auth login` 会在前台等待浏览器授权，不能放到后台；
如果当前环境不能打开浏览器，向用户展示授权入口并让其在可用浏览器完成操作。不要伪造登录状态。

`tmeet auth logout` 会清除本地凭证，属于需用户在下一条消息明确确认的操作。认证失败时停止当前
任务，说明是授权或权限问题；不要通过其他账号、导出文件或通讯录查询绕过。

使用 `tmeet auth --help`、`tmeet auth login --help` 获取当前客户端的准确选项。
