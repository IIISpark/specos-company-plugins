# 会议报告

确认权限和用户请求范围后，再读 `tmeet-report.md` 获取所需子命令参数。

先确认 `tmeet report --help` 和当前权限。`report participants`、等候室记录和参会人导出通常只对
创建者/主持人/联席主持人开放。若参会人查询返回无权限，停止该会议的数据获取，不能改用导出任务绕过。

`participants-export` 是异步操作：提交后保存 `job_id`，按客户端 help 建议轮询 `job-result`，
直到成功得到短期下载链接或明确失败。不要无限轮询；遇到失败保留错误原因并向用户报告下一步。

报告输出默认只展示与请求相关的统计或成员字段。成员回显遵循姓名加必要标识的格式，隐藏手机号、
邮箱、内部 ID 和下载链接中的敏感参数；下载文件写入用户指定或 `working-delta/`、`.tmp/` 临时位置，
未经确认不上传或公开。
