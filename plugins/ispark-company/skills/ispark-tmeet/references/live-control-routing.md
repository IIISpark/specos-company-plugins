# 会中控制

确认目标来源和用户确认要求后，再读 `tmeet-control.md` 获取所需子命令参数。

会中控制要求会议正在进行，操作者具备创建者、主持人或联席主持人权限。使用 `tmeet control --help`
和具体子命令 help，不能猜参数。

呼叫、踢出、移入/移出等候室都会即时影响真人，执行前必须展示会议号、目标成员、动作和是否允许重新
入会，等待用户下一条明确确认。一次确认只覆盖已展示的动作和目标。

`control call` 的会外成员标识可由受限通讯录解析；`kick` 和等候室操作的成员标识必须来自当前会议
参会人或等候室报告，不能使用通讯录结果替代。多名候选目标必须由用户指定；无权限错误停止，不绕行。
